Privacy
Policy

What Vesta touches, why she touches it, and how to take it back.

Vesta is a private household assistant used by three named people. She is not offered to the public, has no users beyond that household, and collects nothing from anyone who reads this page. This policy describes what happens to the Google account data of the people who choose to connect their calendars to her.

What is accessed

Vesta requests a single Google OAuth scope: https://www.googleapis.com/auth/calendar. It allows her to list the calendars on a connected account, read the events on them, check free and busy periods, create and change events, and respond to invitations.

She requests no other scope. She does not access Gmail, Drive, Contacts, Photos, location history, or any other Google service.

Why it is accessed

Solely to answer the household's own questions and carry out its own requests — what is on today, when two people are both free, moving an appointment, accepting an invitation. Calendar data is read at the moment a question is asked and used to compose the reply.

Google user data is never used for advertising, never sold, never shared with third parties, and never used to train any machine learning or AI model.

Where it is kept

On one personal computer in the household. There is no server, no hosted backend, and no external database. Calendar contents are held in memory only for as long as it takes to answer a question, and are not written to disk.

The one thing stored persistently is the OAuth access and refresh token for each connected account, kept in a single file on that computer with owner-only file permissions. Anyone with physical or administrative access to that machine could read that file, which is the same trust boundary as the calendars being open in a browser on it.

Vesta also keeps a short plain-text notes file of things the household has explicitly asked her to remember. It lives on the same machine, and the household can read, edit, or delete it at any time.

What is not collected

  • No analytics, telemetry, cookies, or tracking of any kind, on this website or in the assistant.
  • No data from anyone outside the household.
  • No advertising identifiers, and no profiles built for advertising purposes.
  • No transfer of Google user data to any third party.

Language models

Vesta composes her replies using a large language model provided by Anthropic. To answer a question about the calendar, the relevant calendar details are included in the request sent to that model, under the account holder's own paid subscription. That request is subject to Anthropic's privacy terms. No other processor receives Google user data, and no Google user data is used to train any model.

Limited use

Vesta's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Access can be withdrawn at any moment from myaccount.google.com/permissions, which immediately invalidates the stored tokens. Deleting the local token file removes them from the machine. Once revoked or deleted, Vesta can read nothing further, and nothing about the account remains — there is no copy anywhere else to delete.

Changes

If this policy changes, the revised version replaces this page and the date below is updated. Given the size of the audience, notice will be given in person.
